# YouTune Privacy Policy

**Effective date:** 2026-08-19

YouTune is a browser extension for adjusting audio playback on YouTube and YouTube Music. The current version processes audio locally in the browser and stores user preferences locally in the browser extension storage area.

## Information YouTune collects

The current version does not collect, transmit, sell, or share audio, browsing history, account credentials, or personally identifying information. YouTune does not require an account.

## Local settings

YouTune stores equalizer values, preset selection, processing state, and safety settings locally so that the extension can restore the user's choices. These values remain in the user's browser profile and are not sent to a YouTune server by the current source.

## Website access

YouTune requests access only to YouTube and YouTube Music pages because it must discover the active media element and apply the user's local audio settings. YouTune does not modify video content, collect page content, or upload media.

## Changes

If a future version adds analytics, cloud synchronization, account features, remote services, or any other data practice, this policy must be updated before that version is published.
